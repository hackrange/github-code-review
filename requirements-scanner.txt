# Git Code Review, the python scanning tools.

# These go in their own venv at /opt/gcr/scanner-venv.  semgrep pins a lot of

# Static analysis.  Command injection, SQL injection, XSS, unsafe calls.
semgrep==1.175.0

# A second opinion on secrets.  It hashes what it finds rather than handing
# the value over, so we use it to corroborate rather than to report.
detect-secrets==1.5.0

# A second engine where semgrep reads one file at a time.  bandit is an AST
# rule engine rather than taint analysis, so it corroborates rather than adds
# depth, and the finding says which engine saw it rather than pretending
# otherwise.  gosec, which does add depth, is a binary and lives in the
# Dockerfile beside the other Go tools.
bandit==1.8.6

# still has run_njsscan and skips it when the binary is absent, so this becomes
