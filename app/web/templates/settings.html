Display
Every time on screen is shown in this zone, and a schedule's cron is read in it too — so 0 2 * * * means two in the morning here. Times are still stored as UTC, so changing this never rewrites history. GMT leaves everything on UTC.
Fidelity
A scanner that reports things nobody acts on teaches people to stop reading it. Findings from the rules below are still run and still recorded with their reason — they are kept out of the work list rather than deleted, and one filter shows them again.

Sensitivity labels
What the systems you scan hold. A connection carries these, and an exception can be told not to cover them — so "a plain HTTP link is low" can be true of a brochure site and still not true of the system holding cardholder data.
Company domains
The domains your own sites are on. When a diagram looks for web addresses, any host on one of these, or under one, is offered first and ticked, with the file it was seen in. Domains already recorded on a repository's web addresses count as well, so this is for the ones nothing is recorded on yet.
Limits
A token gets 5000 requests an hour. These keep a long scan under that instead of failing halfway through.
