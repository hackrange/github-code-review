When a model reads a finding as lower than its grade, it also says which other findings deserve the same grade for the same reason. That is kept here as a rule, with a synthetic test: the finding it came from must match it, and anything a model later refused to lower must not. The next finding the rule covers, in a bulk run or on a scan, is graded from the rule without asking the model.
A rule only lowers, never on a credential or a known exploited package, and never over a person's own regrade. It applies in the repository it was learned in until somebody accepts it for every repository, and a rule that matches on a file path alone, with no code to compare, never leaves its repository. A model asked again that reads a finding the rule graded any differently, higher or lower, retires it: every grade it gave is taken back, and each of those findings is sent for its own reading.
