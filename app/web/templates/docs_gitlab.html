Connecting GitLab

Tokens, groups, and what a free instance does not have.
Back to connections
GitLab is the easier of the two. A token is not pinned to one group the way a fine grained GitHub token is pinned to one owner, and there is no per group authorization step, so one connection usually covers the whole instance.

Which token

KindReachesUse it when
PersonalEvery group and project the account can see Scanning an estate. One connection.
GroupThat group and its subgroups Scanning one part of the instance.
ProjectOne project, and no group at all Scanning a single project.

Scopes: read_api and read_repository. Nothing needs write.

Filling in the connection

  • API address — https://gitlab.com/api/v4, or your own host with /api/v4 on the end. Same shape either way: there is nothing different about a self managed instance here.
    Opening that address in a browser returns 404. That is expected. It is a prefix, not a page: /api/v4/projects answers, /api/v4 on its own has nothing behind it. Use the Test button rather than a browser to check it.
  • Web address — the host on its own. Finding links are built from it.
  • Group — the full path including any parent groups, for example acme/platform. Leave it empty to scan every group the token can see; for a personal token that is usually right. Subgroups are always included.

What a project token looks like

A project access token belongs to a project and to no group, so the scan reports no groups came back. That is correct, not a permissions problem: the project is still found through membership, and the warning says so.

What is not available

Dependency alerts, code scanning and secret scanning alerts are GitHub features. GitLab's equivalents are paid tiers and a self managed instance often has none of them, so this asks first and skips them rather than calling an endpoint that is not there and reading the empty answer as good news.

What still runs, which is the bulk of it: secrets across the full history, code analysis, SBOM and dependency vulnerabilities, triage, exceptions and both report files.
