What gets sent

Only what is new. A finding that was here yesterday is not sent again, because a nightly message about the standing backlog is how people learn to filter the sender.

A message never carries the credential itself. It carries the same redacted preview the report files do, because a message lands somewhere with a different set of readers than this page has.

Azure setup
  1. Azure Portal, then App Registrations, then New Registration.
  2. Name it, for example Git Code Review Email, and register it.
  3. Copy the Application (client) ID and the Directory (tenant) ID.
  4. Certificates & Secrets, then New Client Secret, and copy the Value.
  5. API Permissions, then Add a permission, then Microsoft Graph, then Application permissions.
  6. Add Mail.Send, then Grant admin consent.
Application permissions rather than delegated: nobody is signing in, so there is no user to delegate from. Without the admin consent step the permission is listed and does nothing.
Prove it works

Sends one message to everything configured above, with no findings in it. Better to find out here than the first time something is actually wrong.
