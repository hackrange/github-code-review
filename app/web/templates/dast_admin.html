Rule

The rule is a JSON spec that follows the standard. It is checked when you save: it must be in scope, non-destructive, and able to prove a finding (a control, a differential, a way to reproduce it by hand, and a fix).

{# ---- draft a rule from a prompt ---- #} {% if ai_on %}
Draft a rule with AI

Say what to detect, for example: "a detection rule for a PHP-CGI argument injection flaw". The model is told the standard and told to stay non-destructive and in scope. Whatever it writes is checked against the same standard, and a draft always starts disabled for you to review before it runs.
