Custom severity

What a finding is worth here, rather than what the engine guessed.
A scanner grades a rule once, for everybody who will ever run it. That is a reasonable default and a poor answer: a plain HTTP link to an image and a plain HTTP link carrying a session are the same rule and very different risks. Severity is a statement about your risk, so say what it is.
A rule name beats a CWE, because it is the more specific statement. The engine's own grade is kept beside the new one on every finding it changes. Changes apply from the next scan.
