Connection
A fine grained token reaches exactly one resource owner, fixed when the token is made and not changeable afterwards. Create it under the organization, not under your own account, or it authenticates perfectly and sees nothing. One connection per organization. A classic token (ghp_) can cover several once authorized for each under Configure SSO. How to set one up.
App passwords no longer work. Atlassian removed them on 28 July 2026, so this needs an access token — workspace, project or repository — or an API token. A workspace access token with repository:read is the one that behaves like the others here. Bitbucket Cloud only; Data Center is a different API and is not wired up. How to set one up.
A GitLab token usually reaches every group the account can see, so one connection often covers the whole instance. Scopes: read_api and read_repository. A project access token belongs to one project and no group, which is fine and expected: it finds its project through membership. Dependency alerts, code scanning and secret scanning are GitHub features and are skipped here rather than reported as empty. How to set one up.
