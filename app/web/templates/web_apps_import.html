Import web applications

Which repositories are part of a web application, and where it answers
Export the current list

The same file the export writes. Edit it and bring it back.

  • The file is the whole list. A repository in it is marked as part of a web application. One marked now that is not in the file is taken off, and its web addresses are cleared.
  • repository and web_urls are needed on every row. Separate addresses with a pipe ( | ).
  • application_name, application_owner, technical_owner and sensitivity are read when the column is there. A cell that matches what applies now, even when it comes from the connection, changes nothing. A cell that differs is set on the repository itself.
  • The other columns are what a scan found, and are ignored.
  • Only repositories you can see are added, changed or taken off.

Nothing changes until you have seen the list on the next page. A row with a problem is left out, and its repository is not taken off.
