Connecting GitHub

What to create, where to create it, and the one thing that catches everybody.
Back to connections
A fine grained token reaches exactly one resource owner. That owner is chosen when the token is created and cannot be changed afterwards. Create the token under the organization. A token created under your own account authenticates perfectly, reports no error, and sees none of the organization's repositories.

A fine grained token, one organization

The usual choice. One connection per organization.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Resource owner: the organization, not your account. If the Organization permissions section is missing from the form, the resource owner is wrong.
  3. Repository access: all repositories.
  4. Repository permissions — Contents: read, Metadata: read. Add Pull requests: read for pull history, Administration: read for teams and deploy keys, and the Dependabot / Secret scanning / Code scanning alert permissions if you want those findings.
  5. Organization permissions — Members: read, for the access inventory.
  6. Paste it into a connection whose Organization matches.

A classic token, several organizations

Worth it when one credential should cover many. Classic tokens start ghp_; fine grained ones start github_pat_.

  1. Tokens (classic) → Generate new token, scopes repo and read:org.
  2. On the new token's row: Configure SSO → Authorize, once for each organization. An unauthorized organization does not error, it simply vanishes from the results.

If your enterprise blocks classic tokens, use a GitHub App instead: installation tokens are exempt from SAML SSO authorization.

When it does not work

What you seeWhat it means
Signs in, but no repositories Resource owner is your account, not the organization. Not fixable by adding permissions; make a new token.
x-github-sso: partial-results A classic token that has not been authorized for that organization. Configure SSO → Authorize.
Fewer repositories than expected Archived repositories are skipped unless you turn them on in Settings.

The Test button on a connection reports which of these it is.
