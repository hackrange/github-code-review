Take a backup

The file is a zip holding three things: an encrypted copy of the data, a manifest saying when it was made and how much is in it, and a note on how to put it back. The data is encrypted with AES-256-GCM under a key stretched from your password with scrypt, and the manifest is signed along with it, so an edited file fails to open rather than opening wrong.

Credentials travel in the clear inside that encryption, not under this installation's own key. That is what lets the file open on a machine which has never seen this one, and it is why the password matters as much as it does.
